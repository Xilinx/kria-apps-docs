Step 4: Firmware Update¶

The SOM Starter Kits have factory preprogrammed boot firmware that is installed and maintained in the SOM QSPI device. To enable complete board functionality, compatibility with the latest operating systems, and best performance, be sure to install the latest AMD-provided boot firmware following the firmware update instructions available on the Kria Wiki.

If Linux boots without this step (this would be the case majority of the time), you can boot Linux first (using instructions in step 5: Boot Linux) and then use xmutil utility with latest boot firmware to update boot firmware.

If Linux does not boot without this step, you can use Boot Image Recovery Tool to update boot firmware. Download the latest bootfw from K26 Firmware Updates table and follow Image Recovery Tool instructions to update firmware.

The QSPI boot firmware image update persists through power cycles or SD card changes.
