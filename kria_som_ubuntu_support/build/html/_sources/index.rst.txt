************************************************************
PYNQ
************************************************************

PYNQ is an open-source project from Xilinx® that makes it easier to use Xilinx platforms by leveraging the Python and Jupyter ecosystems. It can be readily installed on the KV260 running Ubuntu and includes four open-source designs. PYNQ brings Dynamic Function eXchange (DFX) capabilities, in the form of composable overlays, to Kria SOMs so users can create their own custom data pipelines at runtime directly within the PYNQ environment without using additional development tools: time-multiplexing partial or full hardware designs is easier than ever. The Kria-PYNQ GitHub link can be found `here <https://github.com/Xilinx/Kria-PYNQ>`_.
